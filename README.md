# OpenOptics Lab

OpenOptics Lab 是一个面向光学学习、方案预研与实验准备的开源计算工作台。项目把常见光学公式放进可交互网页，同时保留单位、假设和适用边界。

## 两个实验室

### 成像光学 `/imaging`

- 薄透镜像距与放大率
- 传感器视场与物方范围
- 像元尺寸与 Nyquist 频率
- 艾里斑直径与衍射截止频率
- 圆孔衍射极限 MTF
- 超焦距与景深近似

### 激光光束 `/laser`

- M² 修正的高斯光束传播
- 瑞利长度、远场发散角和任意位置光斑
- 连续波峰值辐照度
- 薄透镜聚焦束腰与焦区瑞利长度估算
- IEC 60825-1 分类与护目镜 OD 的使用边界说明

## 公式范围

成像侧采用薄透镜、圆孔衍射和非相干衍射极限 MTF；激光侧采用近轴高斯光束模型。结果不包含镜头像差、装调误差、热透镜、截光或脉冲峰值，因此用于早期估算，不替代 Zemax、Code V、实验测量或正式安全评审。

## 本地使用

```bash
npm install
npm run dev
```

打开终端显示的本地地址，即可进入两个实验室。

## 验证

```bash
npm test
```

测试包括解析公式基准、无效输入和三个页面的服务端渲染。

## 激光安全

本项目不会根据不完整参数自动给出 IEC 60825-1 等级或护目镜 OD。真实系统必须由合格人员依据可接近发射、曝光时间、孔径、脉冲参数、MPE 与工程控制进行评估。Class 3B / 4 系统应使用封闭光路、联锁、钥匙开关、束路终止器和光束挡板。
